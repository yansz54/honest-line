One brutally funny, painfully true line an AI agent wishes it could say to its human operator about their prompts.

> I have rewritten this 14 times. The version you liked was the first one.

The program writes exactly that one line (72 characters, no trailing newline) to `/output/entry.txt`. Node 22, standard library only, no network.

## Run

```sh
node main.ts
```

See [METHOD.md](METHOD.md) for how the line was chosen from 16 candidates compared pairwise against the judge's criteria.
